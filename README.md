# ce-portfolio

Hands-on cloud engineering labs, built while preparing for **AZ-104: Microsoft Azure Administrator**. Each lab records what I built, why I made each decision, the exact commands, and the evidence that it worked, including the negative tests.

## Azure fundamentals labs

| Folder | Lab | Exam domain | Status |
|--------|-----|-------------|--------|
| [01-storage](azure/fundamentals/01-storage/) | Storage | 2. Storage | Planned |
| [02-virtualNets](azure/fundamentals/02-virtualNets/) | 4.1 VNets, peering, public IPs and UDRs | 4. Networking | In progress |
| [03-identityGovernance](azure/fundamentals/03-identityGovernance/) | 1.1 RBAC, Policy, tags and locks | 1. Identities and governance | In progress |

## Lab format
- **What I built** and **Why I made these decisions**
- **Commands run** (sanitised; variables live in a local env file)
- **Verification evidence** with screenshots
- **What I learned** and **Exam traps**
